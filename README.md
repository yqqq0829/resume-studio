# 简历工坊 · 本地离线简历编辑器

纯前端单文件应用，**无后端、无登录、零外部依赖**——所有数据只存在浏览器 localStorage，全程不上传任何服务器。

## 功能

- 7 套模板（经典 / 现代 / 色块页眉 / 紧凑 / 极简 / 时间轴 / 双栏侧栏）× 5 种标题形态
- 内容教练：量化覆盖率、页数建议、JD 关键词一键补技能
- 简历体检、ATS 安全导出、简历多变体、照片裁剪、撤销/重做
- 导出：单文件 HTML（视觉版 / ATS 安全版）、Word（.doc）、Markdown、纯文本、打印 PDF

## 使用

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

## 技术

原生 HTML / CSS / JavaScript，Canvas 照片裁剪，Intl.Segmenter 中文分词，File System Access API 本地备份。
